# Atelier Python

Un petit éditeur Python dans le navigateur, sur le modèle de Trinket, avec Claude intégré.

- **Exécuter** : le code tourne directement dans la page (Skulpt), avec `input()`, `print()`, `random`, `math` et `turtle` (onglet Tortue).
- **Demander à Claude** : écris dans l'éditeur, en français, le programme que tu veux (ou une question sur ton code). Claude écrit le programme Python niveau lycée à la place de ta demande, avec des commentaires.
- **Corriger avec Claude** : si le programme plante, Claude explique l'erreur et la corrige.

Le fichier `atelier-python.html` est publié comme artifact sur claude.ai : le bouton Claude ne fonctionne que dans cette version. Ouvert ailleurs, l'éditeur et l'exécution Python marchent quand même.
