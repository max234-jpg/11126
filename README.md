# Prospection — sites vitrines

- `docs/` : sites de démonstration publiés sur GitHub Pages (`btp/`, `coiffeur/`, `medecin/`) et visuels des emails (`assets/email/`).
- `emails/` : modèle d'email de prospection, textes par secteur (`build.py`) et coordonnées de l'expéditeur (`config.json`).
- `tools/` : captures d'écran des démos (`shoot.js`) et génération des visuels d'email (`mockup.py`).

Les listes de prospects ne sont jamais versionnées (dépôt public).
